# VCS

## Setup

- Main branch: `main`
- Platform: local git only, no remote yet
- Tickets: none. Work is defined by specs in `aidd_docs/specs/`.
- Hooks: none

## Branches

- Format: `<type>/<short-description>` (for example `feat/home-screen`)
- Types in use: `feat`

## Commits

- Convention: Conventional Commits
- Format: `type(scope): description`, with scopes such as `home`, `event`, `app`, `designsystem`, `data`, `domain`, `plan`, `spec`
- Rules: imperative, lowercase subject, a short body on the why, and a `Co-Authored-By` trailer for AI-made commits

AI should auto commit: after task done
